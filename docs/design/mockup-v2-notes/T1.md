## Interactive state
- `jenis` (default 'FLS3N') and `cabang` (default ''): six jenis pick cards (aria-pressed). The cabang pills change with the jenis and use the exact lists from TALENT-FORM:
  - OSN: 10 bidang
  - Riset: OPSI, FIKSI
  - FLS3N: 16 cabang, with "Tim 2", "Tim 3" and "Tim 5" tags
  - O2SN: 5 cabang
  - Debat: "Debat Bahasa Indonesia (LDBI)" and "Debat Bahasa Inggris (NSDC)"
  - OLPAIN: shows the note "Tidak perlu memilih cabang."
- Pills for cabang already in the list carry a green "Sudah dipilih" tag. Picking one of them keeps "Daftar penjaringan" disabled, with helper "Sudah dipilih. Pilih cabang lain." A jenis that already has a choice can still be picked for a different cabang.
- `bukti`: the dashed dropzone "Unggah sertifikat / PDF, JPG, atau PNG · maks 10 MB" attaches a sample file `sertifikat-<jenis>.pdf` (PDF · 1,1 MB). An x button removes it.
- "Daftar penjaringan" is a real disabled button until jenis + cabang are chosen (OLPAIN needs no cabang). Helper texts: "Pilih jenis talenta dulu." / "Pilih satu cabang dulu." On submit:
  - the new row is added to the list as Terdaftar ("Menunggu pemetaan Kesiswaan", Tahap 1 dari 4)
  - the form resets to no jenis
  - a toast appears: "Terdaftar di penjaringan <jenis> · <cabang>" (Debat uses LDBI/NSDC; OLPAIN has no cabang part)
- `pilihan` rows show: bidang tile + line icon, "Jenis · Cabang", bidang chip, status chip, info line, a 4-segment mini bar with "Tahap N dari 4", and the bukti file or "Tanpa bukti". Terdaftar rows have a quiet sm "Batalkan". It removes the row and shows a toast "<judul> dibatalkan" with an "Urungkan" button.
- `toast`: bottom centre of main, role=status, closes by itself after 6 s, has a close button.
- Riwayat talenta:
  - `minat`: chip input. Chips are remove buttons. Add with Enter or the plus button, max 4.
  - `dikuasai`: text input.
  - `organisasi`, `smp`: textareas.
  - `sert`: file rows with a trash button, plus an "Unggah sertifikat" button, max 2 files.
  - `tersimpan`: quiet "Simpan" shows a green "Tersimpan"; any edit clears it.
