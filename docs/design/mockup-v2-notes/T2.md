## Layout
- The Kesiswaan sidebar is copied from E. "Talenta siswa" is current (`nav nav-on` + aria-current, href Kesiswaan-Talenta.dc.html). Badges are static: Usulan 3, Verifikasi 4.
- Main padding is 22px 28px with a 16px gap (tighter than the spec's 26/36 so everything fits in 1000px).
- Header: h1 "Talenta siswa", subtitle "Penjaringan, pemetaan, dan seleksi peserta pembinaan.", then on the right: quiet "Unduh data (Excel)", the bell and the DR avatar. There is no top search; the table has its own.
- 4 stat tiles, with the value and a short note on one line: Terdaftar (inbox, gray) · Pemetaan (users, blue) · Seleksi/asesmen (clock, orange) · Peserta pembinaan (award, green).
- Pipeline row: segmented buttons with counts, with arrows between Terdaftar → Pemetaan → Seleksi → Peserta pembinaan and a divider before Terdaftar and before Tidak lolos. A green chip "Penjaringan dibuka" sits on the right.
- Body: table card (flex, about 712px) and detail panel (392px, `overflow-y:auto` as a last resort). The default state fits without scrolling.

## Interactive state
- `tahap` (semua/terdaftar/pemetaan/seleksi/pembinaan/tidak) and `jenis` (7 chips, aria-pressed).
  - Chips are tinted with their bidang's `b-*` colour and filled with the solid bidang colour plus a check icon when on. "Semua" is gray, or #3148D6 when on.
- `cabang`: dependent select. There is one `<select>` per jenis inside sc-if, with the option lists from TALENT-FORM. It is disabled for Semua and for OLPAIN ("Tanpa cabang").
- `kelas`: select with optgroups X-1…X-10, X-TAHFIDZ, X-OLIMP · XI-1…XI-12 · XII-1…XII-12.
- `q` searches by nama or NIS.
- Filtering works on the 10 rows. The rows are fixed `<tr>` slots hidden with `.row-hide` (no sc-for inside tbody, same as A). An empty-state row covers the no-match case.
- Counts: tab and stat numbers = base counts + live deltas from the sample rows. Base: Terdaftar 118 · Pemetaan 46 · Seleksi 21 · Peserta pembinaan 58 · Tidak lolos 0 · Semua 243.
  - Tidak lolos starts at 0 because penjaringan is still open.
  - Strip text: "Menampilkan n dari N pilihan talenta", or "n hasil sesuai filter" when a filter is set.
- `checked` holds the row checkboxes, plus a header "select all visible" checkbox. The strip under the filters changes with the selection:
  - Idle: info text.
  - Selected: "n dipilih" + primary sm "Pindahkan ke <next>" + danger sm "Tidak lolos" + "Batal pilih". <next> is "tahap berikutnya" when the checked rows are at mixed stages.
  - "Tidak lolos" turns the strip into a required note input: "Kirim · n tidak lolos" / "Batal". An empty note gives a red border and the placeholder "Catatan wajib diisi".
  - Done: green message + "Urungkan".
- Row actions: icon buttons "Lihat" (eye, aria-pressed, sets `sel`) and "Lolos ke tahap berikutnya" (check; disabled at Peserta pembinaan / Tidak lolos).
- Panel (`sel`, default Hana Safira · OSN Biologi · Pemetaan):
  - Header: avatar, name, "kelas · NIS", and a gold chip "<poin> poin" with "n prestasi di STH".
  - "Pilihan talenta · n": all of the student's choices as buttons that switch `sel`.
  - Bukti dukung file row with "Buka" (#), or a dashed "Tidak ada bukti dukung · Opsional".
  - Riwayat talenta (Minat · Organisasi · Prestasi SMP).
  - Per-row controlled fields: Guru pembina select and Jadwal asesmen date, then the "Catatan pembina · wajib bila tidak lolos" textarea.
  - Actions: primary "Lolos ke <Pemetaan|Seleksi|Pembinaan>" and danger "Tidak lolos". "Tidak lolos" needs a catatan, otherwise the alert "Tulis catatan dulu. Siswa akan menerimanya." appears.
  - Final states show a status box instead: green "Peserta pembinaan · Pembina: <guru>" or red "Tidak lolos · Catatan terkirim ke siswa."
  - After any change the muted line "Siswa menerima notifikasi setiap perubahan tahap." is replaced by "Dipindahkan dari <tahap>. Notifikasi terkirim." with "Urungkan".
- Status chips: Terdaftar c-blue (matches T1) · Pemetaan c-blue · Seleksi c-orange · Peserta pembinaan c-green · Tidak lolos c-red. Table chips wrap to 2 lines (`.stc`), for example "Peserta / pembinaan".
