## Security review (report-only agent, then fixes with tests)
Fixed: HIGH student TOTP lockout (D-66); MEDIUM confirm-password limit + 2FA audit (D-67), PDF scanner bypasses
(D-70), Markdown injection in mails (D-69), Humas access after withdrawn consent (D-71), mail and reset code for a
frozen account, work mail to an unverified staff address (D-68); LOW raw IDN host in the Kesiswaan queue, Talenta
export without password gate/cap, unclamped `$limit`, expired cache rows. Checked and solid: route matrix, file access
IDOR, login/OTP flows, mass assignment, dompdf sandbox, exports, public pages, deploy files. `composer audit` and
`npm audit --omit=dev`: clean.
