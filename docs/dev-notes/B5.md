## Decisions (for DECISIONS.md)
- Role change (#13, lead): approval mode when another Admin exists (no automatic apply), 24 h delay only when the requester is the only Admin; any Admin cancels;
  the Kepsek is notified in delay mode; pending Admin requests count towards the 3-Admin limit; downgrades apply at once.
- Kepsek gets `achievement.export` (UI-MAP §4b). Reports/exports name every student (internal) but never NIS/NISN; XLSX/PDF watermarked "Diunduh oleh … · waktu · dokumen internal".
- Changing a student's archive date also moves `grade12_start_date` (= date − N months) so a later archive-months change keeps the shift; restore needs a new date > today.
- Kepsek "surat atas nama saya" = letters generated since the last applied PrincipalReplacement to that account (all letters if none).
- Letter template = fixed plain-text fields + `{sekolah}`, `{penyelenggara}`, `{tahun_ajaran}` via strtr; number formats stay Admin-only (shown read-only to TU).
- Every letter revocation notifies the Kepala Sekolah (lead, 2026-10-01) — `LetterRevokedNotice` (mail + database).
