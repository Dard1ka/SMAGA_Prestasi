## Decisions / deviations (for DECISIONS.md, @B6)
- **siswa.peringkat = active students only** (no "Tampilkan alumni" toggle), so the "Kamu" row rank equals PersonalRank on
  Beranda/Portofolio (D-37; demo Nadia #14). Alumni stay on `public.peringkat` (linked from the page). Other students' names follow
  the public consent rule; the student's own row shows their own name to themselves only.
- Own row found without exposing ids: by `public_slug` (consent) or by rank + points + count + anonymous label; identical anonymous
  rows are indistinguishable anyway. Own rank under bidang/angkatan filters = same Ranker over the same active set.
- Guru area: guru sees ONLY registrations/talent applications with `mentor_id` = self (also when holding no other permission); a
  guru-only detail page `guru.binaan.show` was added for the 404 rule; letters appear only after TU sent them (LetterPolicy).
- Export is a direct download after a password confirmed in the last 15 min (W2-D's `RequiresRecentPassword`), not SECURITY §3m's
  queue + 15-min signed URL (school-sized data, max 10 000 rows); lead may want the queued variant later.
- Database prestasi "kelas" = the student's current class; "angkatan" = year(grade12_start_date) − 2 (as public pages);
  tahun ajaran = lomba `final_on` (fallback `verified_at`). Points are Excel numbers in the sheet (display only).
