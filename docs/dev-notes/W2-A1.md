## Assumptions / deviations
- Beranda rank follows D-09 (alumni included, same `Ranker` as the leaderboard): demo Nadia shows #15, the mockup shows #14.
- Guru pembimbing is required when registering (needed for the SPT guru letter); default = the lomba's `default_mentor_id`.
- Decline: the member row keeps `declined_at`; if all remaining members confirmed and ≥ 2 people remain the team goes to menunggu_kepsek,
  if only the leader remains it stays menunggu_konfirmasi (leader cancels and registers again). `InviteMembers` (UI-MAP #11) not built.
- Usulan "Tautan resmi" → `website_url`, "Catatan" → `description`. Persyaratan tab is derived (participation, team size, mentor, juknis);
  Jadwal = registration dates, start, final, report deadline (setting days). Invalid/unsafe stored URLs are not rendered.
- Tour: Esc closes it for this page view only (no page script); it returns until "Lewati"/"Mulai" stores `tour_seen_at`.
- New screen not in UI-MAP: `siswa.undangan.show` → `Siswa\KonfirmasiTim` (link of TeamInvitation + Beranda "Perlu tindakan").
- Test infra: `Storage::fake('local')` uses one folder shared by parallel test containers and wipes it on start → random 404s in file
  tests. My tests use `LombaFixtures::isolatedDisk()` (per-PID root, removed afterEach); other agents may want the same.
