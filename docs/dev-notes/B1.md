## Decisions (for DECISIONS.md, B6/lead)
- K10 (lead): Admin student reset = random 12-char temporary password (no 0/O/1/l/I), shown once in a dialog, valid 72 h, must be changed;
  reset also lifts a freeze. > 10 resets (student + staff events) by one Admin in 1 h → one alert to every Admin per hour.
- K1: window applies only while `must_change_password` and `initial_password_expires_at` is set (null = no window: accounts made before B1 get a
  fresh 14 days from the migration; staff accounts have none). Expired/frozen logins get the generic login error (K11); the page already says
  "Kesulitan masuk? Hubungi admin sekolah." Changing the window affects the next imports only.
- K3: only student accounts in `pending_activation`; the 10th wrong password freezes, ends sessions, alerts Admin + Kesiswaan. K2 reopen
  (Kesiswaan/Admin, `student.import`) lifts it; a "Bukan saya" freeze only Admin can lift (`UnfreezeAccount` or K10 reset).
- K8: notice on activation (to the bound email) and on email change (old + new); link = signed URL + single-use `email_notices` row, 7 days;
  the page needs a button press (mail scanners). Freeze works for any role; ticket = `AccountAlert` to every Admin. Change-email OTP reuses purpose `verify_email`.
- K9: CSV is `;`-separated with UTF-8 BOM (Indonesian Excel), formula-safe cells, masked NIS/email, needs a password confirmation from the last 15 min,
  audited `account.activation_report_exported`. Flag "di luar jam sekolah" = Mon–Fri 06:30–15:30 Asia/Jakarta (assumption).
